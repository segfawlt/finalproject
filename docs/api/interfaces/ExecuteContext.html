    Interface ExecuteContext

    Abstraction over the Discord.js REST API for tool execution.

    One instance wraps a single Discord guild (identified by guildId). The implementation lives in apps/server/ and uses botClient.

    Error contract: All methods throw on Discord API failure. Error classification (transient vs permanent), retry with backoff, and rollback are the execution engine's responsibility — not this layer's. ExecuteContext is stateless. It does not track what was created or deleted.

# Project Presentation

`index.html` is a self-contained 15-slide technical/academic presentation of the project. It is intended for a roughly ten-minute architecture overview before a separate live demo.

## Open and control the presentation

Open `docs/presentation/index.html` directly in a browser; no server or build step is required.

- `ArrowRight` / `ArrowLeft`: advance or go back
- `Space`: advance when no interactive control is focused
- `PageUp` / `PageDown`: go back or advance
- `Home` / `End`: jump to the first or last slide
- Click the **Previous** / **Next** buttons

The browser's print dialog can be used to print the presentation or save it as a PDF.
